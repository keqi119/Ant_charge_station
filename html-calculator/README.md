# 便民充电站单枪收入与融资租赁测算

这是一个可直接离线运行的单文件经营与融资测算工具。正式成品位于：

`../outputs/01a0089d-c14c-76d1-a1fc-c095a30f2935/便民充电站单枪收入与融资租赁测算.html`

## 使用方法

1. 使用当前稳定版 Google Chrome 或 Microsoft Edge。
2. 双击 HTML 文件即可打开，不需要安装软件、启动服务器或连接互联网。
3. 蓝色字段为可编辑输入；修改有效参数后，城市分配、投放、运营、融资和情景结果会在本机重新计算。
4. 页面会自动保存最近一次有效方案。点击“保存方案”可下载完整 JSON 方案文件；在另一台电脑打开同一 HTML 后，点击“打开方案”即可恢复。
5. “恢复基准”会先要求确认，确认后清除当前编辑并恢复批准的基准参数与内嵌历史数据。
6. “打印/PDF”只打印当前模块；建议使用横向页面。

## 内嵌数据与 Excel 导入

- 当前内嵌经营数据共 3,049 行，期间为 2026-06-16 至 2026-08-15。
- 导入文件必须为 `.xlsx` 或 `.xls`，并包含名为 `Data List` 的工作表。
- `Data List` 必须保持批准的 16 列表头、顺序和数据类型；日期使用 `YYYY-MM-DD`，站点 ID 与站点名称不得为空，枪数必须为正数。
- 订单总额与充电电费、充电服务费的累计差额不得超过 1 元。
- 系统会先完整校验再替换数据；导入失败不会覆盖当前有效方案。

## 模型检查与风险提示

- “情景分析、检查与来源”模块展示 17 项可见检查。所有检查通过后，结果才被视为数学上自洽。
- 总部月度费用和经营税率基准值当前为 0，摘要会持续显示黄色提示；正式融资材料应在取得真实预算和税务意见后补充。
- 所有计算、自动保存和导入均在浏览器本地完成；成品 CSP 明确禁止网络连接。方案文件会重新校验内置城市审计来源，并保存最近测算时间、检查结果、数据期间和关键输入摘要。HTML 和方案 JSON 不承诺加密；敏感文件请使用电脑权限或加密存储保护。
- 本工具是项目经营和融资方案模型，不构成法律、会计、审计、税务或投资建议。融资合同、资产权属、税务处理和会计确认应由相应专业人士复核。

## 开发与验证

在 `html-calculator` 目录执行：

```powershell
npm ci
npm run verify
```

该命令会运行单元测试、重建单文件、执行离线发布检查，并使用已安装的 Chrome 与 Edge 完成端到端测试。
