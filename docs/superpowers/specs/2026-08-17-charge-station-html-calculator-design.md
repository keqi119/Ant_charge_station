# 便民充电站单枪收入与融资租赁 HTML 测算表设计

版本日期：2026-08-17

交付形式：单文件离线 HTML

业务口径基准：`2026-08-16-charge-station-financing-model-design.md`

## 1. 目标与范围

本项目把已经完成并验证的 Excel 模型转换为一个可在 Windows Chrome 或 Edge 中双击打开的交互式 HTML 测算表。HTML 版本面向项目团队和债权类资方，必须在无服务器、无网络、无安装步骤的环境中完成历史数据更新、经营预测、融资租赁测算、情景分析和结果展示。

HTML 版本完整覆盖现有 Excel 的 12 个业务模块，但不模拟 Excel 单元格界面。它采用专用投融资系统式布局，在不改变业务口径的前提下提高操作效率、风险提示清晰度和现场演示效果。

以下内容不在本期范围内：多人实时协作、云端账户、服务器数据库、在线审批、法定会计报表、税务申报、电子签章和自动向外部机构发送资料。

## 2. 交付与运行约束

最终成品命名为 `便民充电站单枪收入与融资租赁测算.html`，HTML、CSS、JavaScript、图表代码、Excel 解析组件、当前城市数据和当前历史数据全部嵌入同一个文件。

- 双击文件即可在当前稳定版 Chrome 或 Edge 中运行。
- 运行时不得请求外部 CDN、接口、字体或统计服务。
- 所有业务数据保存在用户本机，不上传网络。
- 页面以电脑宽屏编辑为主；窄屏可以查看融资摘要，但不保证适合编辑宽表。
- 打印时隐藏导航和操作按钮，支持打印当前模块；融资摘要提供适合资方阅读的专用打印版式。

## 3. 总体架构

单文件内部逻辑分为四层，各层通过明确的数据对象连接：

1. **数据层**：内置当前 3,049 行历史记录、56 城数据库、季节曲线、来源信息、模型版本和基准假设。
2. **导入与持久化层**：解析同结构 Excel，校验后以事务方式替换历史数据；在浏览器本地保存当前方案，并支持方案文件导入导出。
3. **计算层**：复用现有 JavaScript 纯计算引擎的业务规则，负责历史单枪标定、城市分配、站型、投放、运营、租赁、现金流、DSCR 和情景分析。
4. **展示层**：负责 12 模块导航、输入组件、数据表、KPI、图表、检查状态、打印和错误反馈。

统一数据流为：

`输入校验 → 历史单枪基准 → 城市与站型分配 → 月度投放 → 运营收入与 CFADS → 融资租赁 → 资金缺口与 DSCR → 摘要和情景`

任一上游步骤失败时，下游不得发布新的计算结果；页面保留最近一次有效结果并显示错误来源。

## 4. 页面布局与导航

采用用户确认的“左侧目录＋固定工作区”布局。

### 4.1 顶部工具栏

顶部固定显示：

- 方案名称；
- 当前模型版本和最近计算时间；
- 模型总状态：通过、警告或失败；
- `导入 Excel`、`保存方案`、`打开方案`、`恢复基准`、`打印/PDF` 操作。

恢复基准操作必须二次确认，并只恢复内置基准方案，不删除用户已下载的方案文件。

### 4.2 左侧目录

左侧固定显示 12 个模块及各自状态：

1. 融资摘要
2. 核心假设
3. 城市数据库
4. 城市分配
5. 月度投放计划
6. 单站成本
7. 历史原始数据
8. 历史单枪模型
9. 年度季节曲线
10. 36 月运营模型
11. 融资租赁与资金缺口
12. 情景分析、检查与来源

状态颜色只作辅助，必须同时使用文字或图标区分，避免只依靠颜色传递含义。

### 4.3 主工作区

- 可编辑输入使用蓝色边框和明确单位；计算结果只读。
- 跨模块结果提供来源提示，可定位到来源模块。
- 历史原始数据、城市数据库和 60 个月表格使用冻结表头、搜索、筛选、分页和横向滚动。
- 关键输入修改后自动重新测算；重计算期间显示状态但不阻塞页面导航。
- 融资摘要使用 KPI 卡片、服务费与 CFADS 趋势、融资缺口与租赁余额、DSCR、期限比较和风险提示。

## 5. Excel 导入

页面打开时直接加载内置的当前历史数据和当前基准结果。用户可选择同结构 Excel 文件更新历史基准。

### 5.1 文件契约

- 必须存在名为 `Data List` 的工作表。
- 必须包含现有源文件所使用的 16 个必要字段。
- 解析组件及许可证文本随 HTML 一并嵌入，导入不访问网络。

### 5.2 校验门禁

导入后、替换数据前必须校验：

- 日期、站点编号和站点名称有效；
- DC/AC 枪数、订单数、充电量、时长和金额字段为有效数值；
- 有效站点日的枪数大于零；
- `订单总金额 = 电费 + 服务费`，全表累计绝对差额不超过 1 元；
- 记录保留原始工作表行号，错误可定位到具体行；
- 成熟站筛选和历史汇总结果可正常形成。

校验失败时显示错误清单并保持原数据和原结果不变。校验全部通过后，才原子性替换当前历史数据并触发完整重算。

## 6. 计算范围与口径

HTML 版不读取 Excel 中已经计算出的结果，而是依据相同业务口径重新计算。现有 JavaScript 计算函数是主要参考实现；HTML 版不得用展示层公式另建一套不同口径。

### 6.1 历史和季节

- 按站点和有效运营日形成成熟站样本。
- 计算成熟站单枪日服务费 P25、P50 和加权核对值。
- 使用现有年度季节曲线还原全年基准。
- 保留历史总金额、电费、服务费、订单数、充电量和枪数等勾稽。

### 6.2 城市和投放

- 保留 56 城数据、26 个首批城市、城市等级和来源质量标记。
- 目标总枪数必须为正偶数，基准为 30,000 枪。
- 首批城市按标准配额优先分配，其他城市按等级、有效指标得分和排名补充。
- 最后一个补充城市可获得剩余偶数枪数，但总量必须精确等于目标。
- 2 枪站和 4 枪站数量必须为非负整数，并与城市枪数完全勾稽。
- 基准 12 个月投放；慢建设情景 18 个月，首批城市仍须在前 6 个月首次上线。

### 6.3 运营和 CFADS

- 计算轴为 60 个月；前 36 个月为正式报告期，第 37 至 60 个月为债务尾期。
- 服务费收入按运营枪数、年均单枪日服务费、自然月天数、季节指数、月龄爬坡和城市调整系数计算。
- 物业结算严格二选一：固定月租或服务费分成。
- CFADS 扣除物业成本、其他经营成本、总部费用和经营税。
- 电费代收代付和订单总金额只作交易规模辅助，不进入基准 CFADS。

### 6.4 融资租赁和资金缺口

- 每个上线月形成独立资产和租赁批次。
- 供应商账期、融资放款延迟和首期租金时点与现有模型一致。
- 期限仅允许 18、24 或 36 个月；融资比例、利率、延迟和留购比例使用已批准范围。
- 等额月租单独折现末期留购款；每批租赁最后一期后余额必须在分币容差内归零。
- 资金缺口依据含融资放款、不含股东注资的累计现金曲线计算。
- 月度无债务服务时 DSCR 显示为空；年度和全期 DSCR 使用总 CFADS 除以总债务服务。

### 6.5 情景

保留六类组合情景：基准、保守收入、融资收缩、放款延迟、慢建设和综合压力；保留 18/24/36 个月期限比较。情景结果必须由完整计算链重新生成，不得只对摘要结果乘系数。

## 7. 本地保存与方案文件

- 页面自动保存最近一次有效的输入和当前模块位置。
- 大体量历史数据使用浏览器本地数据库保存，小型界面偏好可使用浏览器键值存储。
- 用户可下载独立方案 JSON 文件，并在另一台电脑的同一 HTML 中打开。
- 方案文件包含模型版本、保存时间、方案名称、输入参数、城市覆盖设置、历史数据期间、历史数据摘要和完整历史记录。
- 打开方案时必须校验版本、必要字段、数值范围和完整性；失败时不覆盖当前方案。
- HTML 不对本地数据提供加密承诺。涉及敏感信息时，用户应通过文件访问权限和加密存储介质保护文件。

## 8. 错误、警告与审计

### 8.1 错误

以下情况阻止发布新结果：导入契约失败、必填数据无效、目标枪数不是正偶数、站型无法整数勾稽、融资参数超出批准域、留购款超过融资本金、租赁余额未归零或内部计算出现非有限数值。

错误必须显示字段或行号、原因和修复建议。页面保留最近一次有效结果，不用零或空白覆盖。

### 8.2 业务警告

负现金流、资金缺口和低 DSCR 是业务结果，必须如实显示，不作为程序错误隐藏。总部费用或经营税为零时，摘要和相关模块保持黄色提示，并标注结果为“税前、未计未录入总部成本”。

### 8.3 模型检查

页面保留与 Excel 对应的 17 项可见检查及总状态。每次计算和保存方案时记录模型版本、计算时间、数据期间、主要输入摘要和检查状态。

## 9. 性能与兼容性

目标运行环境是普通办公电脑上的当前稳定版 Chrome 和 Edge：

- 首次打开原则上不超过 5 秒；
- 修改单个核心参数后，主结果原则上 1 秒内更新；
- 导入约 3,049 行同规模报表原则上 10 秒内完成；
- 长表使用分页或虚拟化展示，避免一次创建数千个复杂 DOM 行；
- 计算在浏览器本地执行，不依赖网络速度。

性能目标属于验收指标；若目标设备性能明显不足，页面必须给出进度状态，不得表现为无响应。

## 10. 测试与验收

### 10.1 公式单元测试

覆盖历史筛选、季节还原、城市评分、城市配额、站型转换、部署计划、运营收入、物业二选一、CFADS、单批租赁、逐批租赁、现金瀑布、DSCR、六情景和期限比较。

### 10.2 基准对照

使用现有最终 Excel 和当前 JavaScript 引擎作为黄金基准，至少核对：

- 目标枪数 30,000；
- 总投资 640,300,000 元；
- 三年服务费收入 1,547,192,645.96 元；
- 三年 CFADS 1,083,034,852.17 元；
- 租赁放款 543,300,000 元；
- 峰值资金缺口 229,020.49 元，发生于 2026-11；
- 全期 DSCR 3.2105 倍；
- 最低月度 DSCR 1.8551 倍；
- 三年末租赁余额 141,715,483.68 元。

金额比较按分币容差，比例和 DSCR 使用明确的小数容差；不得用格式化后的展示字符串参与计算。

### 10.3 浏览器验收

自动化或可重复检查必须覆盖：

- 单文件在断网环境打开；
- 12 模块顺序和导航状态；
- 当前历史数据直接加载；
- 同结构 Excel 导入成功；
- 错误 Excel 不覆盖当前方案；
- 核心输入修改后相关结果联动；
- 方案自动保存、下载、重新打开和恢复基准；
- 17 项检查及总状态；
- 图表无控制台错误；
- 当前模块和融资摘要打印版式；
- Chrome 和 Edge 的关键流程。
